# Mitgliedschaften & Bescheinigungen

## Eigene Mitgliedschaften ansehen

Unter **Profil → Mitgliedschaften** findest du alle Rollen, die du innehast oder früher innehattest – jeweils mit Gremium, Rolle und Zeitraum. Mit dem Schalter **Zeige nur aktive Mitgliedschaften** blendest du beendete Mitgliedschaften aus.

![Eigene Mitgliedschaften mit Rolle, Gremium und Zeitraum](/screenshots/memberships.png)

Mitgliedschaften werden von [Moderator:innen](/user/moderation/rollenmitgliedschaften) eingetragen. Fehlt etwas oder ist ein Datum falsch, wende dich an die Moderator:innen deiner Studierendenschaft.

::: info
Neue Zuordnungen sind in angeschlossenen Anwendungen manchmal erst am nächsten Tag wirksam.
:::

## Tätigkeits-Bescheinigung erstellen

Aus deinen Mitgliedschaften kannst du ein PDF erzeugen, das deine ehrenamtliche Tätigkeit belegt – etwa für einen Antrag auf ein Flexsemester, BAföG-Verlängerung oder eine Bewerbung.

1. Öffne **Profil → Mitgliedschaften** und klicke auf **Tätigkeits-Bescheinigungen**.
2. Wähle die Mitgliedschaften aus, die in der Bescheinigung erscheinen sollen. **Alle auswählen** bzw. **Alle abwählen** hilft bei langen Listen.
3. Wähle unter **Was benötigst du?** eine Vorlage aus, sofern deine Studierendenschaft welche angelegt hat (z. B. *Flexsemester-Antrag*).
4. Klicke auf **Bescheinigung generieren**.

![Auswahl der Mitgliedschaften und der Vorlage für eine Tätigkeits-Bescheinigung](/screenshots/membership-export.png)

### Mit Anschreiben

Je nach Vorlage wird der Übersicht ein Anschreiben vorangestellt, mit Briefkopf der Studierendenschaft, Absender, Empfänger, Betreff und Text. Absender- und Empfängeradresse werden dabei aus den Profilen übernommen.

::: warning Fehlende Anschrift
Erscheint ein Hinweis wie *„In deinem Profil ist keine Anschrift hinterlegt“*, ergänze sie zuerst unter [Profil → Stammdaten](./profil#stammdaten) – sonst fehlt sie im Anschreiben.
:::

Moderator:innen und Administrator:innen können Bescheinigungen auch für andere Mitglieder erstellen.

Ohne Vorlage enthält der Export nur die Übersicht der Mitgliedschaften. Wie Vorlagen angelegt werden, steht unter [Mitgliedschaften-Export](/user/administration/einstellungen#mitgliedschaften-export).
