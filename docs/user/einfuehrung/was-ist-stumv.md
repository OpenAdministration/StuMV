# Was ist StuMV?

Die **Studentische Mitgliederverwaltung (StuMV)** verwaltet die Mitglieder von Organisationen wie Studierendenschaften oder Vereinen. Sie beantwortet vor allem drei Fragen:

1. **Wer gehört dazu?** – Alle Personen mit einem Konto in eurer Studierendenschaft.
2. **Wer macht was?** – Personen werden Rollen in Gremien zugeordnet, jeweils mit Start- und Enddatum. So bleibt nachvollziehbar, wer wann in welcher Funktion aktiv war.
3. **Wer darf was?** – Aus den Rollen leiten sich Rechte ab, die an andere Anwendungen weitergegeben werden, z. B. an das Finanzsystem StuFiS, an Mailinglisten oder an jede Anwendung, die OpenID Connect unterstützt.

## Ein Konto für viele Dienste

StuMV ist ein *Identity Provider*: Andere Anwendungen eurer Studierendenschaft können den Login an StuMV abgeben. Mitglieder brauchen dann nur ein Konto und ein Passwort. Wer eine Rolle verliert, verliert automatisch auch die damit verbundenen Rechte in den angeschlossenen Diensten.
