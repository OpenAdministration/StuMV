# Die Oberfläche

![Übersicht einer Studierendenschaft mit der Seitenleiste links](/screenshots/dashboard.png)

## Seitenleiste

Links findest du die Navigation. Welche Einträge du siehst, hängt von deinen [Zuständigkeiten](./zustaendigkeiten) ab:

| Eintrag | Sichtbar für | Inhalt |
| --- | --- | --- |
| **Übersicht** | alle | Startseite mit Kacheln zu allen Bereichen |
| **Profil** | alle | deine persönlichen Daten |
| **Gremien und Rollen** | alle | Gremienbaum, Rollen und deren Mitglieder |
| **Mitglieder** | alle | alle Personen der Studierendenschaft |
| **Moderator:innen** | alle | Liste der Moderator:innen |
| **Administrator:innen** | Moderator:innen, Admins | Liste der Administrator:innen |
| **Rechte** | Admins | [Rechtegruppen](/user/administration/rechtegruppen) |
| **Mailinglisten** | Admins | [Mailinglisten](/user/administration/mailinglisten) |
| **Einstellungen** | Admins | [Einstellungen](/user/administration/einstellungen) |
| **Hilfsmittel** | Moderator:innen, Admins | [Hilfsmittel](/user/moderation/hilfsmittel) |
| **Aktivitätsprotokoll** | Admins | [Aktivitätsprotokoll](/user/administration/aktivitaetsprotokoll) |

Auf dem Smartphone ist die Seitenleiste eingeklappt und lässt sich über das Menüsymbol oben links öffnen.

## Kopfzeile

Oben zeigt die Brotkrumen-Navigation, wo du dich gerade befindest. Rechts findest du

- das Menü **Synchronisieren** (nur Administrator:innen, siehe [Synchronisation](/user/administration/synchronisation)),
- dein Profilmenü mit **Abmelden**.

## Listen und Suche

Fast alle Listen (Mitglieder, Rollen, Gremien, …) haben oben ein Suchfeld, das die Liste beim Tippen filtert. Viele Einträge haben rechts ein Menü mit weiteren Aktionen wie *Bearbeiten* oder *Löschen*.

## Löschen bestätigen

Folgenreiche Löschaktionen (z. B. ein Gremium mitsamt seinen Rollen) musst du bestätigen, indem du einen vorgegebenen Text – meist den Namen – in ein Textfeld tippst. So wird verhindert, dass versehentlich etwas Wichtiges gelöscht wird.
