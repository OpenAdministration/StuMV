# Zuständigkeiten & Rechte

StuMV kennt fünf Zuständigkeitsstufen. Jede höhere Stufe hat in ihrem Bereich auch die Rechte der darunterliegenden.

| Zuständigkeit | Bereich | Typische Aufgaben |
| --- | --- | --- |
| **Mitglied** | eigenes Konto | Profil pflegen, Gremien und Mitglieder ansehen, Bescheinigungen erstellen |
| **Gremien-Moderator:in** | ein Gremium und seine untergeordneten Gremien | Rollen anlegen, Personen zuordnen, Mitgliedschaften beenden |
| **Moderator:in** | ganze Studierendenschaft | zusätzlich Gremien anlegen, bearbeiten und löschen; Moderator:innen ernennen; Hilfsmittel |
| **Administrator:in** | ganze Studierendenschaft | technische Verwaltung: Rechtegruppen, Mailinglisten, Domains, Anbindung anderer Anwendungen |
| **Superadmin** | alle Studierendenschaften | Studierendenschaften anlegen, Betrieb der Installation |

## Was darf wer?

| Aktion | Mitglied | Gremien-Mod. | Moderator:in | Admin |
| --- | :-: | :-: | :-: | :-: |
| Eigenes Profil bearbeiten | ✓ | ✓ | ✓ | ✓ |
| Gremien, Rollen und Mitglieder ansehen | ✓ | ✓ | ✓ | ✓ |
| Rollen anlegen, bearbeiten, löschen | | ✓¹ | ✓ | ✓² |
| Personen Rollen zuordnen | | ✓¹ | ✓ | ✓² |
| Gremien-Moderator:innen ernennen | | ✓¹ | ✓ | ✓² |
| Gremien anlegen, bearbeiten, löschen | | | ✓ | ✓² |
| Moderator:innen ernennen | | | ✓ | ✓ |
| Hilfsmittel (Einladungen, Abgleiche) | | | ✓ | ✓ |
| Administrator:innen ernennen | | | | ✓ |
| Rechtegruppen & Mailinglisten | | | | ✓ |
| Einstellungen, Domains, Clients | | | | ✓ |
| Aktivitätsprotokoll | | | | ✓ |

¹ nur im eigenen Gremium und dessen untergeordneten Gremien
² wenn die Person zugleich Moderator:in ist

::: tip Moderation ≠ Administration
Moderator:innen kümmern sich um das *Wer macht was* (Gremien, Rollen, Personen). Administrator:innen kümmern sich um das *Wer darf was* (Rechte und die Anbindung anderer Anwendungen). Beide Zuständigkeiten sind getrennt und können unterschiedlichen Personen gehören.
:::

## Wie bekomme ich eine Zuständigkeit?

- **Moderator:innen** werden von bestehenden Moderator:innen oder Administrator:innen ernannt – siehe [Moderator:innen](/user/moderation/moderatorinnen).
- **Gremien-Moderator:innen** werden von Moderator:innen des Gremiums oder eines übergeordneten Gremiums ernannt.
- **Administrator:innen** werden von bestehenden Administrator:innen oder von den Betreiber:innen der Installation ernannt.

Wer in deiner Studierendenschaft welche Zuständigkeit hat, siehst du in der Seitenleiste unter **Moderator:innen** bzw. **Administrator:innen**.
