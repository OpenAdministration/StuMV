# Rollenmitgliedschaften

Rollenmitgliedschaften sind das Herzstück von StuMV: Sie halten fest, wer wann welche Funktion hatte, und bestimmen, welche Rechte jemand in angeschlossenen Anwendungen erhält.

Verwalten können sie Moderator:innen der Studierendenschaft sowie Moderator:innen des Gremiums oder eines übergeordneten Gremiums.

![Mitglieder einer Rolle mit Start, Ende, Beschlussdatum und Kommentar](/screenshots/role-members.png)

## Personen einer Rolle zuordnen

1. Öffne **Gremien und Rollen**, wähle das Gremium und dann bei der Rolle **Alle Mitglieder**.
2. Klicke auf **Mitglied hinzufügen**.
3. Wähle eine oder mehrere Personen aus.
4. Trage die Daten der Mitgliedschaft ein:

   | Feld | Pflicht | Bedeutung |
   | --- | :-: | --- |
   | **Start** | ✓ | Ab wann die Person die Rolle innehat. |
   | **Ende** | | Bis wann. Leer lassen für unbefristet. |
   | **Beschlussdatum** | | Wann die Wahl bzw. der Beschluss stattfand. |
   | **Kommentar** | | Freitext, z. B. ein Verweis auf das Protokoll. |

5. Speichere die Zuordnung.

![Formular zum Zuordnen von Personen zu einer Rolle](/screenshots/add-role-member.png)

::: info Wann wird die Zuordnung wirksam?
Liegt das Startdatum in der Zukunft, wird die Mitgliedschaft erst dann aktiv. Auch sonst kann es bis zum nächsten Tag dauern, bis angeschlossene Anwendungen die neuen Rechte kennen – der Abgleich läuft automatisch jede Nacht. Administrator:innen können ihn auch [sofort anstoßen](/user/administration/synchronisation).
:::

::: tip Person noch nicht in der Liste?
Es lassen sich nur Personen auswählen, die bereits ein Konto in der Studierendenschaft haben. Neue Personen kannst du mit dem Hilfsmittel [Zur Registrierung einladen](./hilfsmittel#zur-registrierung-einladen) einladen und dabei direkt Rollen vorgeben.
:::

## Mitgliedschaft bearbeiten

Wähle in der Mitgliederliste der Rolle bei einer Person **Bearbeiten**. Du kannst Start- und Enddatum, Beschlussdatum und Kommentar ändern.

## Mitgliedschaften beenden

Wenn jemand eine Funktion abgibt, **beende** die Mitgliedschaft, statt sie zu löschen. So bleibt die Historie erhalten – und die Person kann später eine [Tätigkeits-Bescheinigung](/user/mitglieder/mitgliedschaften#tatigkeits-bescheinigung-erstellen) erstellen.

### Einzelne Mitgliedschaft beenden

Wähle bei der Person **Mitgliedschaft beenden** und gib das Datum an, zu dem sie endet.

### Mehrere Mitgliedschaften auf einmal beenden

Typisch nach einer Wahl, wenn eine ganze Amtszeit endet:

1. Öffne die Mitgliederliste der Rolle und wähle **Mitgliedschaften beenden**.
2. Wähle die Personen aus, deren Mitgliedschaft endet.
3. Gib das **Ende der Mitgliedschaft** an und bestätige.

## Mitgliedschaft löschen

Löschen entfernt die Mitgliedschaft vollständig, als hätte es sie nie gegeben. Das ist nur für **fehlerhafte Einträge** gedacht, etwa wenn versehentlich die falsche Person zugeordnet wurde.
